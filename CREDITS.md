## Community server operators

The following operators keep MS Chat / Comic Chat interop alive today, decades after Microsoft discontinued the client. This port would have nothing to connect to without them:

- **The Crypt** (`www.crypthome.com`) — a small memorial server running OfficeIRC with full IRCX, the original MS Chat protocol.
- **Comic Chat Network / dedoky** (`comic.dedoky.com`) — community plain-IRC server.
- **Koach.com** (`chat1.koach.com`) — long-running community server.

## Server directory

- **Mermaid Elizabeth** ([mermeliz.com](https://mermeliz.com/)) — maintains the [Comic Chat server list](https://mermeliz.com/srvr_rms.htm) that made finding these servers possible, and hosts an archive of the original Microsoft Comic Chat 2.5 client download.
